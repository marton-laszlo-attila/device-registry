 
# Készíts el egy eszköznyilvántartó alkalmazást!

 

### A nyilvántartónak rendelkezni kell:

    szerződés adatok
    eszközök

 

Egy eszköztípus több szerződésen is rajta lehet, viszont eszközönként más gyári számmal. (N:N)

A feladathoz egy REST-apit kell készíteni, nem kell hozzá felület.

 

### Megvalósítandó feladatok:

    eszköz létrehozása, módosítása törlése, lekérdezése (lista és egy konkrét elem)
    szerződés létrehozása, módosítása, törlése, lekérdezése (lista és egy konkrét elem)
    szerződés lekérdezéskor jelenítsük meg a rajta lévő eszközöket, fontos, hogy listában nem kell szerepeljen
    eszköz hozzáadása / levétele szerződésről

 

### Követelmények:

    CRUD REST-api.
    Egységes hiba kezelés
    API forgalom: request / response logolása adatbázisban
    Elérhető OPEN api dokumentáció, egy publikus URL-en BASIC AUTH-al ellátva

 

### Megvalósítással kapcsolatos követelmények:

    Laravel 13
    Egy támogatott PHP verzió, lehetőleg php 8.5 https://www.php.net/supported-versions.php
    MySQL
    Cleancode (SOLID, DRY)
    Tartsd be a PSR-4 és PSR-12 standardeket (https://www.php-fig.org/psr/)
    Docker csomag (docker-compose.yaml) legyen mellékelve a megoldásban
    Migrációkból fel lehessen állítani a projektet

 

A megoldásodat egy nyilvános git repoban oszd meg velünk.
